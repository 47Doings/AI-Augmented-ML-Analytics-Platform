Analytics Platform prototype

1. Choose your data

A made-up subscription company with deliberate data problems. Pick a question, then generate its data. Each use case is a configuration file plus SQL; the platform code is the same for all of them.

Upload one CSV file where each row is one record (a customer, a loan, an order ...). Up to 10 MB and 200,000 rows, UTF-8. The file is kept only in your private workspace. The AI never sees rows: only summary figures and category names from the results.

Columns to learn from

Only tick columns you would know before the outcome happens. A column recorded afterwards (such as a cancellation date or a final status) makes the model look perfect and be useless; the platform warns about suspiciously good columns, but you know your data best.
